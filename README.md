# 小澜 · FDE 三面全套路演交付物

笔记侠 FDE 加速营三面（48 小时沙盘）的完整交付物。赛题：为澄野商业打造"强人群洞察老板 Agent"。

## 这是什么

三面要求 48 小时内把一个模糊需求（"我要一个团队愿意用的 Agent"）变成完整的产品方案和路演。这套交付物包含从需求澄清到方案设计到路演材料的全链路产出。

## 交付物清单

| 产出 | 位置 | 说明 |
|------|------|------|
| 架构图 | `架构图.html` | 产品架构图（HTML 交互版） |
| 路演 PPT | `PPT/index.html` | 12 页 PPT（HTML 版，浏览器打开即看） |
| 演讲稿 + Demo 清单 | `docs/演讲稿+Demo操作清单.docx` | 12 分钟路演稿 + 演示步骤 |
| 采用与风险说明 | `docs/采用与风险说明.docx` | 12 个评委追问预判 + 风险应对 |

## 项目背景

- 团队三人：高佳慧（文档/PPT/路演）、Edward/梁曦霖（全部代码）、邵俊钦（数据清洗）
- 佳慧角色：独立完成 PRD、12页PPT、演讲稿、架构图、采用与风险说明、12个评委追问预判
- 路演 12 分钟 + 8 分钟追问，评委评价"你们不是把 FDE 等同于外包"

## 快速查看

- 架构图：浏览器打开 `架构图.html`
- PPT：浏览器打开 `PPT/index.html`
- 文档：`docs/` 目录下的 docx（需要 Word 或 WPS）

## 核心能力体现

这套交付物证明了"技术翻译能力"——把模糊需求"我要一个团队愿意用的 Agent"转化成：
1. 结构化的需求澄清
2. 可交付的产品方案
3. 能上台讲清楚的路演材料
4. 提前预判的 12 个评委追问
